## 0. Executive brief

You asked for a **whole-site colour scheme change**: more **jet black**, **silver**, **aurora** vibes — planned by a full expert team, grounded in:

1. **Grok Imagine studies** (old brass museum targets + new jet/silver re-targets)  
2. **Our real 3D model** (`orrery-webgl` + `img/engine/*.webp`)  
3. **What already works** (model-first layout, glass UI, single Three stack)  

**Verdict of the expert board:**  
The live product should stop fighting the model. The **Earth texture already lives on pure black with a silver-blue atmospheric limb**. Brass/parchment was a keepsake fantasy; **jet + silver + aurora is the honest UI language of the photoreal engine**.

| Pillar | Decision |
|--------|----------|
| Canvas | Near-true **jet black** (`#000000` → `#0A0A0C`), not warm brown-black, not navy-indigo |
| Metal | **Brushed silver / chrome** UI chrome — hairlines, icons, frames |
| Glow | **Aurora** = cool white→ice-blue→soft violet from Earth’s limb (not gold, not terracotta) |
| Hero | **Live 3D model** is the brand mark; UI floats as glass on the void |
| Gold | **Retire from UI.** Optional **tiny** sun-glint only on Sun body / prices (max 1 token) |

## 2. Expert board (full resource team)

### A) Art Director — Brand & colour

**Mandate:** One coherent metal language.

**Proposed token system — “Jet Silver Aurora” (v1)**

| Token | Hex | Role |
|-------|-----|------|
| `--ap-jet` | `#000000` | Absolute void (orrery stage) |
| `--ap-jet-soft` | `#07070A` | Page body (slight lift for text comfort) |
| `--ap-jet-raised` | `#101014` | Cards / plates |
| `--ap-jet-elevated` | `#18181E` | Hover / elevated glass fill |
| `--ap-silver` | `#C8CDD6` | Primary metal / secondary text |
| `--ap-silver-bright` | `#E8EBF0` | Primary text (starlight silver) |
| `--ap-silver-dim` | `#8B919C` | Muted labels |
| `--ap-chrome` | `#A8B0BC` | Icons, hairlines, inactive chrome |
| `--ap-aurora` | `#7EC8E8` | Links, active nav, limb glow |
| `--ap-aurora-deep` | `#4A9FD4` | Aurora mid |
| `--ap-aurora-violet` | `#8B7CE0` | Optional secondary glow (sparingly) |
| `--ap-cta` | linear `#6AB0FF → #A8C4E8` | Primary actions (silver-aurora, **not** flat blue brick) |
| `--ap-cta-ink` | `#050508` | Text on CTA |
| `--ap-sun` | `#E8DCC8` | **Rare** — Sun body highlight / price only |

**Laws**

1. No brass body text. No terracotta. No parchment cream UI.  
2. Silver = structure; Aurora = life/active; Jet = stage.  
3. Gold is **not** a UI colour (export plate may still use engraved gold as *product art*).  
4. Contrast: silver-bright on jet-soft ≥ 7:1 for body; aurora on jet ≥ 4.5:1 for links.

**Deliverables when implementing**

- Rewrite `css/ap-palette-2026.css` as sole token source  
- Retarget `ap-observatory-enchanted`, `ap-visual-clarity`, `ap-model-stage`, `ap-site-polish`  
- Kill residual `#C2A05E` / `#D97B52` in page CSS (≈1500 brass/gold-ish hits across 67 CSS files — purge via tokens, not line-by-line chaos)

### D) Frontend Systems — How we ship without breaking tools

**Token cascade (load order)**

1. `ap-palette-2026.css` — jet/silver/aurora tokens + legacy aliases  
2. Page critical CSS  
3. `ap-visual-clarity.css` — type/contrast  
4. `ap-model-stage.css` — layout around model  
5. `ap-site-polish.css` — last-mile overrides  

**Alias strategy (so 1500 hits don’t all need hand edits)**

```css
:root {
  --brass: var(--ap-chrome);           /* was gold metal → silver chrome */
  --gold: var(--ap-silver);            /* UI gold → silver */
  --gold-bright: var(--ap-silver-bright);
  --terracotta: var(--ap-cta);         /* CTA alias */
  --ap-void-deep: var(--ap-jet-soft);
  --ap-cyan: var(--ap-aurora);         /* keep cyan name → aurora */
}
```

Then **phase-2** replace hard-coded hex in hot paths (index inline, chart-critical, shop).

**Injection**

- Keep `app.js` + `ap-page-boot.js` ensure*Css chain  
- Bump SW to new version after palette land  

**Tests / gates**

- Visual-check pages: home, chart, mysky, shop, explore, aries  
- axe a11y 0 serious  
- dualThree = false  
- Engine strip still last-in-main  
- Forms functional (chart cast path)
