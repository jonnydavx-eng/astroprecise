## (A) One vision

AstroPrecise is a **private observatory that freezes real sky**: cool void `#0C1016`, engraved brass `#C2A05E`, photoreal planetary *windows* (live orrery or engine stills), and engraved seals as instrument stamps — never stock nebulas or emoji planets.  

**Product spine:** Chart · Sky · Daily · Readings · Library · Shop (primary nav locked).  
**Moment** is the **keepsake layer** (More → Keepsake + homepage path + Chart/Sky deep links): free on-device card, paid pack when checkout lives.  

**Marketing/lifestyle** = Imagine AI · **Sky truth plates** = engine `captureFrame` · **Personal numbers/names** = code only.
