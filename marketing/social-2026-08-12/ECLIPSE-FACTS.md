# The eclipse facts — one copy, and every post in this tree must match it

Written 2026-08-09 (Claude @ BOOK-T1H4NJ753R) after 82 wrong-fact hits were found across
the 25 posts in this folder. They had all drifted the same way: someone wrote a national
figure once, everyone else copied it, and nobody re-derived it. Hence one file.

**If a post disagrees with this table, the post is wrong.** If this table is wrong, fix it

## Wednesday 12 August 2026 — what Britain actually gets

| | |
|---|---|
| First contact | **18:08 – 18:17 BST**, depending where you are |
| Maximum | **19:05 Edinburgh · 19:12 London · 19:16 Truro** |
| Coverage | **88 – 96%** of the Sun, deepest in the far south-west |
| Last contact | **≈20:10 BST**, before sunset everywhere in Britain |
| Eclipse point | **20°02′ Leo** |
| Totality | **Greenland, Iceland, northern Spain. Never Britain.** |
| Greatest eclipse (global) | **18:46 BST** = 17:46 UT, 45 km off western Iceland |

## The five things that kept going wrong

1. **19:05 is Edinburgh, not "the UK".** It was printed as a national maximum in most of
   the tree. It is the *earliest* of the three, so any post that also said "deepest in the
   south" was wrong twice — the south is both deeper *and* later.
2. **91% is not the UK figure.** Nor is 89–92%. The honest figure is a range, 88–96%.
   Where one number is unavoidable, write "nine-tenths" — it is true everywhere in Britain
   and it reads better out loud.
3. **First contact is not "just after 18:00".** It is 18:08–18:17. An alarm set for the
   old figure is fine (18:00 gives you time to get outside); a caption claiming the bite
   starts at 18:00 is not.
4. **Greatest eclipse is off western Iceland, not "over the Arctic".** It is at about 65°N,
   south of the Arctic Circle. The totality *track* reaches the Arctic; the greatest point
   does not.
5. **17:46 is UT, not TD.** See the timescale note below — this one bit the website too.

## The timescale note (the 70-second question)

Greatest eclipse is **17:47:06 TT** — NASA/GSFC Besselian elements for 2026 Aug 12.
ΔT (TT−UT1) in mid-2026 is **69.1 s**, from the USNO/IERS long-term prediction file
(2026.50 = 69.11 s, 2026.75 = 69.09 s). So:

```
17:47:06 TT  −  69.1 s  =  17:45:57 UT  =  18:45:57 BST  →  18:46 BST
```

The site and several posts printed **"17:46 TD"**. That was the UT figure wearing the wrong
label: **17:46 is UT, 17:47 is TT.** The BST minute was right by luck, and it survives the
correction, but the label did not.

NASA's own page quotes 17:45:51 UT because it still carries ΔT = 75.4 s, predicted back in
2006 — the Earth then sped up rather than slowing. 17:45:51 and 17:45:57 both round to
18:46 BST, so the printed minute is safe against that whole disagreement.

**In copy, write "18:46 BST (17:46 UT)".** Do not write TD or TT in anything a reader sees;
neither is on the banned list, but both cost a reader and buy nothing.

## Banned words — social is exactly where these lose people

Never in a caption, on-screen text, alt text, or a voice-over:

> **sextile · orb · midheaven · ephemeris · arcminute**

Their vocabulary instead: big three · placements · moon sign · rising · birth chart ·
Saturn return · retrograde.

Keep the precision as a **feeling** — "to the minute you were born", "we do not round" —
never as a technical noun. Point any anti-woo at the **industry**, never at the reader.
